# SAFEMINE-Fall-Detection-Vitals-Monitoring-System
**SAFEMINE** is an IoT-based fall detection and vital monitoring system for high-risk environments. An ESP8266 wearable monitors heart rate, SpO₂, and impacts, sending data via 433 MHz LoRa to an ESP32 gateway. Firebase securely stores telemetry, while a PWA dashboard provides real-time alerts and incident history.
